Make me a landing page for Tortuga, our distributed-tracing tool for SREs running microservices. Audience is senior backend engineers between incidents, evaluating us against Datadog/Honeycomb. Brand is technical and blunt, no hype. About the examples

Build directly examples start with the prompt shown. There may be choices along the way, but no follow-up prompts to polish the design. You’d usually refine further from here.

Older baselines had image generation disabled. The new Opus 5.5 and GPT-6 Sol comparisons make it available with and without Impeccable. Some runs were resumed after technical fixes.

Design first adds a step before any code. Impeccable has an image model draw a few options for the page, a person picks one, and the coding model builds the website to match. The picture on the left is that generated image. The one on the right is a screenshot of the working site. These are selected examples, with human reviews and feedback along the way.
