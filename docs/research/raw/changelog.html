Skillv4.8.0October 26, 2026

Devin, findings on your pull requests, and checked engine downloads.

Impeccable now installs into Devin and knows a Replit Agent project when it sees one. The detector can annotate a pull request on GitHub, and every engine download is checked against digests that ship with the skill.

  • Devin and Replit Agent. npx impeccable install sets the skill up for Devin on the web, in the CLI and on Desktop, and accepts windsurf as another name for it. A project with a .replit file is read as Replit Agent, so the installer names it, not Codex CLI, when it writes to .agents. Thanks to @faocampo and @Kodylow for asking.
  • Findings on the pull request. In a GitHub Actions job, impeccable detect --github turns each finding into an annotation on the line that caused it. --list-rules prints every rule with its category and description, and --scope or --no-advisory narrows the list. Thanks to @mvanhorn for both.
  • A second look at hard offset shadows. A crisp shadow pushed 4px or more is flagged as an advisory, not a failure, because it can be a deliberate neobrutalist choice. Keep one with data-impeccable-ignore="hard-offset-shadow". Thanks to @mager for the contribution.
  • Cursor checks the edit it just made. The design hook runs after each write instead of gating it, with one scan per edit. update and doctor --fix move an existing hook over.
  • Hooks find your projects. A session started in a folder above your projects now gets the end-of-session review for each project it edited. Codex hooks in your user folder are detected, and doctor checks their launcher. Thanks to @Shandy1972v.
  • Checked engine downloads. The launcher, the npm package and install compare each engine download with a list of digests committed alongside the skill, not one published next to the file, and refuse a binary that does not match. Thanks to @jojig-dao for the design.
  • Installs that hold up. A slow download waits as long as data keeps arriving, instead of failing at 120 seconds. If an update cannot reach the bundle, your installed skills stay as they are. Every Windows .cmd ships with CRLF line endings, Copilot global hooks work on Windows, and the commands Impeccable prints run in PowerShell.
  • Live mode. Tune values survive closing the panel and reloading the page (thanks to @mager). Patching a page's Content-Security-Policy meta tag no longer corrupts the file, and phones no longer raise the keyboard when live mode loads.
  • Fewer false alarms. straggler measures the last word instead of estimating it, and sees a text-wrap: pretty that Firefox dropped (thanks to @stedmanhalliday for both). design-system-radius no longer reads the numbers inside calc(), min() or max() as radii (thanks to @iamceph). Text dimmed by a stepper's resting state is an advisory, while text a script parked mid-reveal still counts. In a monorepo, each file's design tokens come from its own package first. A negative value in a margin shorthand is no longer lost. Legal and footnote blocks are exempt from line length and tiny text. URL scans skip cookie notices, splash gates and hidden mockups, and contrast reads gradient text and dark surfaces correctly. Images set through srcset count, and cramped-padding sees through a transparent wrapper (thanks to @BibaPutt).
  • Side stripes on table rows. A colored stripe down one side of a status row or cell now reports as a side tab, in URL scans as well as file scans, and an !important reset stands it down.
  • Arabic-script text. harden now covers ZWNJ, Yeh and Kaf variants, local digits and calendars for Arabic-script languages. Thanks to @FawwazLawal.
  • Fixes. Ask for more directions than the weighing supports and new work shows the ones that earned a place and says so, instead of padding the hand (thanks to @tehzunm-ctrl). **/ in an ignore pattern stops at folder boundaries, so one waiver no longer skips an unrelated page. Live mode starts in a page that blocks storage. Audit's contrast and touch-target checks match WCAG AA. Thanks to @srobroek.

Skillv4.1.0August 14, 2026

A better way to choose a direction.

Choosing a direction stopped being a menu and became a design review: the roll argues with itself in front of you, and what it shows you are pages you could ship rather than mood boards. Native apps got a verification pipeline that stops pretending they are websites, Windows works, and the build path is finally yours to set.

Choosing a direction

  • The roll argues with itself, in front of you. Every dealt world now carries a verdict, and the direction you are handed has already taken what the losing worlds did better. You choose from a hand that has been fought over.
  • What you approve looks like a page. Full-fidelity comps replaced the old sketches, which came back too rough to decide from. Generation costs the same at any fidelity, so the draft quality was buying nothing.
  • Steer the next hand instead of re-rolling blind. Safer and bolder aim the roll along the familiar-to-bold axis, and IMPECCABLE'S PICK shows the model's own favourite when the dice chose otherwise.
  • The deck reads as a gradient of standing. Contenders, then the category standard, then the demoted row last. Stacked raise callouts became a compact cycler, so the assigned card stopped towering over its neighbours.
  • Adding a page keeps the world you already have. Once identity is settled, cards differ in composition rather than character, and each comp anchors on a screenshot of a page you already shipped.
  • The board still works with no image generation. A text-only card keeps its full read on the front, and art that fails to load collapses to a field painted from the card's own palette instead of a dark void.

Native apps stop being treated as websites

  • Verification knows what platform it is on. The comp side of the system was platform-aware while everything that checked the work assumed a browser. The verify-and-review pipeline now has a native leg, so an iOS or Android build is reviewed as an app.
  • Polish gathers native evidence. Its classify, triage, and verify steps map per platform instead of asking for browser evidence that a native app cannot produce.
  • The detector stops contradicting itself. Web-only checks no longer fire against native surfaces they were never written for.

The build path

  • Comp-first or code-first is your call now. Comp-first buys bolder composition for time; code-first is leaner and writes the ambition into the contract instead. init asks once, with the trade stated.
  • Change your mind mid-round. Every board carries the toggle: flip it and the open cards start generating comps without closing the round, flip back and anything already rendered stays.
  • Existing projects never re-run setup. On a project that has recorded nothing, the first flip asks whether to keep it. One machine can differ from the team in .impeccable/config.local.json.

It runs where you run it

  • Windows works. Installs no longer trip the POSIX hook guard, the runtime probe survives cmd.exe metacharacters, the decision page opens in your browser, and a successful roll stops aborting on the way out.
  • Plugin subagents actually load. Marketplace installs shipped four subagents that Claude Code silently never loaded, because the generated manifest carried a key that suppressed them.
  • Two more harnesses. Hermes Agent and Google Antigravity install and run natively, and pinned skills read correctly on Codex.
